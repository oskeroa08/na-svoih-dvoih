# «На своих двоих» — обновлённая версия сайта

Статический сайт на HTML, CSS и JavaScript без фреймворков, сторонних библиотек, внешних шрифтов и внешних изображений. Фото находятся в `assets/images/` и используются локально; исходные тяжёлые JPEG оптимизированы в WebP.

## Как посмотреть

Откройте `index.html` в браузере. Для локальной проверки с сервером можно выполнить в папке проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Перед публикацией — обязательно

1. Откройте `site-config.js` и задайте реальный телефон и/или email центра. В полученном архиве не было подтверждённых рабочих контактов, поэтому я не подставлял выдуманный номер из экспорта Framer.
2. Если нужна отправка формы напрямую на сервер, подключите форму к выбранной CRM или endpoint. Сейчас при заданном `email` форма готовит письмо через `mailto:` (посетитель должен отправить его из почтового приложения). Если email не задан, сайт честно сообщает, что сообщение не отправлялось.
3. Проверьте и при необходимости утвердите тексты о специализации и опыте до публикации.
4. Убедитесь, что у вас есть разрешение на публикацию предоставленных фотографий.

## Структура

- `index.html` — семантическая разметка и весь контент страницы.
- `styles.css` — адаптивная вёрстка, визуальные состояния и анимации с поддержкой `prefers-reduced-motion`.
- `script.js` — мобильное меню, форма, год в футере и анимация появления блоков.
- `site-config.js` — редактируемые контакты.
- `assets/images/*.webp` — реальные фото команды, сжаты для веба.
